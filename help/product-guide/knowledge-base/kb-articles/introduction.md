# Base de connaissances Experience Manager Guides

La base de connaissances contient des articles pratiques et axés sur des scénarios pour Experience Manager Guides, qui couvrent les configurations, les personnalisations et les cas d’utilisation courants au-delà de la documentation de base du produit.

| Catégorie | Description |
|---|---|
| Création | Conseils et techniques pour créer et réutiliser du contenu dans l’éditeur, y compris la personnalisation de l’éditeur, la gestion des métadonnées et la validation du contenu. |
| Framework d’extension Guides | Découvrez comment personnaliser l’interface utilisateur de Experience Manager Guides, depuis la prise en main du framework d’extension jusqu’à la création de composants personnalisés, de widgets et de personnalisations dans la section Révision de l’application . |
| Source de données externes | Conseils sur l’intégration et la configuration des connecteurs de sources de données externes avec Experience Manager Guides. |
| Publication | Bonnes pratiques relatives à la génération de sortie, notamment Native PDF, DITA-OT, les modèles AEM Sites et les configurations de publication basées sur des microservices. |
| Workflows | Configurez et utilisez des workflows de post-génération pour automatiser les étapes après la génération de la sortie. |
| Traduction | Instructions sur la manière d’améliorer les performances de traduction et de gérer le contenu inclus ou exclu de la traduction. |
| Cas d’utilisation | Découvrez les scénarios réels tels que le contenu conditionnel, l’utilisation de clés et les variables de contenu contextuel dans la sortie publiée. |
